# OmniDesk UI Wireframes / Mockups

This folder contains the UI wireframe/mockup screenshots for the OmniDesk platform.

## Purpose

The wireframes define the main user interface structure before development. They show the layout, navigation, forms, tables, dashboards, and management screens required for the platform.

## Screens Included

### 1. Login Page
A split-panel login screen with OmniDesk branding, email/password inputs, Google SSO option, password visibility toggle, and “Keep me signed in” option.

### 2. Dashboard
A dashboard overview showing ticket statistics, category breakdown, priority distribution, and a recent tickets table.

### 3. Ticket List Page
A ticket management screen with search, filters, status tabs, sortable ticket table, agent avatars, and pagination.

### 4. Create Ticket Page
A ticket submission form with title, description, category, priority, attachment upload, and a right sidebar showing priority guidance, tips, and SLA response times.

### 5. Ticket Details Page
A detailed ticket view with ticket metadata, comment thread, activity timeline, add-comment box, status update options, assigned agent information, and SLA warning.

### 6. Admin Panel
An administration screen for managing users, roles, ticket categories, and system activity logs.

## Design Direction

The mockups follow a modern enterprise SaaS dashboard style with:
- Clean layout and structured navigation
- Sidebar-based dashboard experience
- Status and priority badges
- Tables, forms, and analytics cards
- Professional IT support workflow design

These wireframes are part of the Week 1 planning deliverables and may be refined during implementation.

## Note

These UI mockups represent an initial demo design for the OmniDesk platform. They are intended to show the main structure, layout, and user experience direction for the first planning phase.

The final application design may include additional screens and improvements, such as:
- Homepage / landing page
- Register page
- Forgot password page
- Reports page
- Notifications page
- User profile page
- Settings page
- Improved responsive mobile views

The current mockups are not the final UI. They will be refined and expanded during the development phase.
