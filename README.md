# OmniDesk

Unified IT Help Desk & Ticket Management Platform

## Overview
OmniDesk is a full-stack web application designed to manage IT support tickets, role-based workflows, notifications, dashboards, and reporting.

## Main Features
- User authentication and role-based access
- Ticket creation and management
- Ticket assignment workflow
- Comments and notifications
- Dashboard and reporting
- Admin panel

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: ASP.NET Core Web API
- Database: SQL Server
- Authentication: JWT
- Tools: GitHub, Figma, Draw.io, Postman

## Project Structure
- frontend/ — React frontend application
- backend/ — ASP.NET Core Web API
- database/ — SQL scripts and ERD files
- docs/ — project documentation
